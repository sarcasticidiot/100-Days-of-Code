# 100 Days of Code - C Programming

A repository documenting my **100 Days of Code** journey as I learn and practice the C programming language.

## Repository Structure

Each day has its own folder containing the code, exercises, and problems completed that day.

* `Day 1/` to `Day 24/` — Daily practice and coding exercises
* `build/` — Compiled files and build artifacts
* `.gitignore` — Keeps unnecessary files out of the repository

## About

* **Language:** C
* **Editor:** Visual Studio Code
* **Platform:** macOS
